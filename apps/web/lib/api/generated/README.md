# Generated API client

This directory is generated by [Orval](https://orval.dev) from the backend's OpenAPI spec (`apps/api/openapi.json`).

**Never hand-edit anything in this directory.** Regenerate with `pnpm codegen` from the repo root after changing a backend DTO or endpoint.

It is committed to git on purpose, so a fresh clone type-checks and builds without a running database.
