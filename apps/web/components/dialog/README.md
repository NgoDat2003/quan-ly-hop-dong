# components/dialog/

Dialog tái dùng ở ≥2 feature (vd: confirm-dialog dùng chung cho mọi thao tác xoá/xác nhận). Dialog riêng của 1 feature (nhiều sub-component, form riêng) đặt trong `features/{feature}/components/dialog/{ten-dialog}/` thay vì ở đây.

Chưa có component nào — thư mục này chỉ giữ chỗ theo `.agent/projectRules/frontend-architecture.md`.
