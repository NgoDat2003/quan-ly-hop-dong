# components/table/

Helper dùng chung cho TanStack Table (data-table wrapper, pagination, column-header) khi ≥2 feature cần hiển thị bảng dữ liệu.

Chưa có component nào — thư mục này chỉ giữ chỗ theo `.agent/projectRules/frontend-architecture.md`. Tạo `data-table.tsx` ở đây khi feature đầu tiên thực sự cần bảng, không tạo trước khi chưa có nhu cầu.
